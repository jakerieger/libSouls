## v0.2.0 — Oct. 11, 2026

- ELDEN RING `MSBE` map format (ported from SoulsFormatsNEXT).
- `.sl2` save files
- Havok `.hkx` tagfile format parsing.
- `TAE` format update
- Added `GPARAM` and `FXR`
- C API covers majority of the C++ library now.
- [BinderKeys](https://github.com/JKAnderson/BinderKeys) and [Paramdex](https://github.com/soulsmods/Paramdex) now
  vendored with repo.
- Local documentation can be generated via Doxygen:
    - `doxygen Doxyfile` outputs to `Docs/html`

[Download](https://github.com/jakerieger/libSouls/archive/refs/tags/v0.2.0.zip)
